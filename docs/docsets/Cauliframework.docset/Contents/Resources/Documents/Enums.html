Enumerations

The following enumerations are available globally.

  • HTTPArchive

    Turns records into an HTTP Archive (HAR 1.2), which Chrome DevTools, Firefox, Charles, Proxyman and other tools can open.

    let data = try HTTPArchive.data(for: records)
try data.write(to: fileURL)

    A HAR file contains the full requests and responses, including tokens and cookies. Failed requests have the status 0 and the error in the _error field of their response.
