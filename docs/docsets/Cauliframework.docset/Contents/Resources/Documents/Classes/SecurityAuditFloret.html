SecurityAuditFloret

public class SecurityAuditFloret : InterceptingFloret
extension SecurityAuditFloret: DisplayingFloret

The SecurityAuditFloret checks every request Cauli intercepts for privacy and security problems, e.g. credentials sent over plain HTTP, tokens in URLs or insecure cookies.

let audit = SecurityAuditFloret(firstPartyHosts: ["example.com"])
let cauli = Cauli([InspectorFloret(), audit])

Each problem comes from a SecurityAuditRule. Add your own to defaultRules. Only URLs and headers are checked, not bodies. The floret counts from its creation until reset(). Ignored findings are kept across app starts.
