NetworkUsageFloret

public class NetworkUsageFloret : InterceptingFloret
extension NetworkUsageFloret: DisplayingFloret

The NetworkUsageFloret measures how much the app uses the network and suggests how to use less: the bytes sent and received, compression, caching, protocols and connection reuse, per host and per endpoint.

It counts from the moment it is created until reset(). Every NetworkUsageRule it is created with is evaluated on the recorded usage, and each finding is shown as a hint.

let usage = NetworkUsageFloret()
let cauli = Cauli([InspectorFloret(), usage])
cauli.run()
…
usage.snapshot.totals.receivedBytes
usage.hints.map(\.title)

Only requests Cauli intercepts are counted. Requests the RecordSelector excludes, or that are passed through because they exceed its limit, are missing.
